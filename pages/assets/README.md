# Znak PSP używany w serwisie

Plik `herb-psp.png` jest wersją internetową oficjalnego znaku graficznego
Państwowej Straży Pożarnej, przygotowaną z zasobu 300 dpi będącego w dyspozycji
KG PSP. Zmniejszenie do 320 px służy wyłącznie optymalizacji strony; proporcje,
kolory i treść znaku nie zostały zmienione.
